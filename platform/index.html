Spawn Operator Console

Launch and preview real Spawn workflows from the browser.

This frontend is connected to the repository manifest and CLI, so it can preview live `spawn --dry-run` output and submit real headless launches when credentials are configured.

Why this wrapper matters

  • Give non-terminal operators a buyer-ready control plane.
  • Turn Spawn into a platform surface for demos, onboarding, and governed launches.
  • Connect product UX directly to the existing agent × cloud matrix.
